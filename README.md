# Amazon-Style E-Commerce Website

A front-end Amazon-inspired e-commerce website built using HTML and CSS. 
This project was created to practice web development, page structure, styling, layouts, and responsive design.

## Technologies Used

- HTML5
- CSS3
- Font Awesome

## Features

- Amazon-style navigation bar
- Search bar
- Location and account sections
- Product category boxes
- 4-image product cards
- Product labels and "See more" links
- Hero section
- Footer with multiple sections
- Responsive layout
